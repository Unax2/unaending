동사 어미

동사에 붙는 어미는 어떤 형태(ます형 또는 て형)에 붙느냐로 크게 두 종류로 나뉩니다. 먼저 어간을 어느 형태로 바꿔야 하는지부터 확인하세요.

01 — ます형(연용형) 어미

어간을 ます형으로 바꾸기

아래 어미들은 동사를 ます형 어간(ます를 뗀 형태)으로 바꾼 뒤 붙입니다. 그룹별 변환 규칙은 다음과 같습니다.

그룹별 ます형 어간 만들기
1그룹(5단동사)
어미 う단 → い단으로 교체
書かく(쓰다) → 書かき
話はなす(말하다) → 話はなし
読よむ(읽다) → 読よみ
2그룹(1단동사)
어미 る를 그대로 탈락
食たべる(먹다) → 食たべ
見みる(보다) → 見み
불규칙동사
する(하다) → し
来くる(오다) → 来き

※ 1그룹은 어미가 く・ぐ・す・つ・ぬ・ぶ・む・う・る 무엇이든 う단→い단이라는 같은 규칙 하나로 통일됩니다. (반면 아래 て형은 어미별로 규칙이 갈립니다 — 02 참고)

어미의미결합 예시 (書く)
〜ます정중형, 현재/미래 긍정 "~합니다"書かき + ます → 書かきます（씁니다）
〜ません정중형, 현재/미래 부정 "~하지 않습니다"書かき + ません → 書かきません（쓰지 않습니다）
〜ました정중형, 과거 긍정 "~했습니다"書かき + ました → 書かきました（썼습니다）
〜ませんでした정중형, 과거 부정 "~하지 않았습니다"書かき + ませんでした → 書かきませんでした（쓰지 않았습니다）
〜たい희망(1인칭) "~하고 싶다"書かき + たい → 書かきたい（쓰고 싶다）
〜たがる희망(제3자) "~하고 싶어하다"書かき + たがる → 書かきたがる（쓰고 싶어하다）
〜ながら동시동작 "~하면서"書かき + ながら → 書かきながら（쓰면서）
〜やすい"~하기 쉽다"書かき + やすい → 書かきやすい（쓰기 쉽다）
〜にくい"~하기 어렵다"書かき + にくい → 書かきにくい（쓰기 어렵다）
〜そう양태(직접 관찰) "~일 것 같다"書かき + そう → 書かきそう（쓸 것 같다）
02 — て형(연결형) 어미

어간을 て형으로 바꾸기

아래 어미들은 동사를 て형으로 바꾼 뒤 붙입니다. て형은 그룹뿐 아니라 1그룹 안에서도 어미 글자에 따라 소리가 달라지는 음편(音便)이 있어 주의가 필요합니다.

그룹·어미별 て형 만들기
1그룹 동사 어미 く
く → いて
書かく(쓰다) → 書かいて(써서/쓰고)
聞きく(듣다) → 聞きいて(들어서/듣고)
(예외: 行く(가다)→行って(가서/가고))
1그룹 동사 어미 ぐ
ぐ → いで
泳およぐ(수영하다) → 泳およいで(수영해서/수영하고)
脱ぬぐ(벗다) → 脱ぬいで(벗어서/벗고)
1그룹 동사 어미 ぬ・ぶ・む
ぬ・ぶ・む → んで
死しぬ(죽다) → 死しんで(죽어서/죽고)
遊あそぶ(놀다) → 遊あそんで(놀아서/놀고)
読よむ(읽다) → 読よんで(읽어서/읽고)
1그룹 동사 어미 う・つ・る
う・つ・る → って
買かう(사다) → 買かって(사서/사고)
待まつ(기다리다) → 待まって(기다려서/기다리고)
乗のる(타다) → 乗のって(타서/타고)
1그룹 동사 어미 す
す → して
話はなす(말하다) → 話はなして(말해서/말하고), 貸かす(빌려주다) → 貸かして(빌려줘서/빌려주고)
2그룹 / 불규칙동사 て형
2그룹 동사
る 탈락 + て
食たべる(먹다) → 食たべて(먹어서/먹고)
見みる(보다) → 見みて(봐서/보고)
불규칙동사
して / 来きて
する(하다) → して(해서/하고)
来くる(오다) → 来きて(와서/오고)
어미의미결합 예시 (書く)
〜ている진행 "~하고 있다" / 상태 "~해 있다"書かいて + いる → 書かいている（쓰고 있다）
〜てもいい허가 "~해도 된다"書かいて + もいい → 書かいてもいい（써도 된다）
〜てはいけない금지 "~하면 안 된다"書かいて + はいけない → 書かいてはいけない（쓰면 안 된다）
〜てから순서 "~하고 나서"書かいて + から → 書かいてから（쓰고 나서）
〜てみる시도 "~해 보다"書かいて + みる → 書かいてみる（써 보다）
〜てください요청 "~해 주세요"書かいて + ください → 書かいてください（써 주세요）
〜てしまう완료·아쉬움 "~해 버리다"書かいて + しまう → 書かいてしまう（써 버리다）
구분 포인트. ます형 어미는 정중함·희망·동시동작처럼 문장을 끝맺거나 명사처럼 연결하는 어미가 많고, て형 어미는 진행·허가·금지처럼 다른 동사(いる, みる, しまう 등)와 이어 붙는 복합 표현이 많습니다.

い형용사 어미

い형용사는 어미 「い」를 뗀 어간에 대부분의 어미가 붙습니다. です만 예외적으로 어간이 아니라 기본형 그대로에 붙습니다.

01 — 어간 만들기

어미 「い」 탈락

어간 만드는 법

기본형에서 마지막 글자 い를 떼면 어간입니다.
예) 高たかい(비싸다) → 어간 高たか / 寒さむい(춥다) → 어간 寒さむ

어미의미결합 예시 (高い)
〜です정중형 "~ㅂ니다" (예외: 기본형 그대로 + です)高たかい + です → 高たかいです（비쌉니다）
〜くない부정 "~하지 않다"高たか + くない → 高たかくない（비싸지 않다）
〜くありません정중 부정 "~하지 않습니다"高たか + くありません → 高たかくありません（비싸지 않습니다）
〜かった과거 "~했다"高たか + かった → 高たかかった（비쌌다）
〜くなかった과거 부정 "~하지 않았다"高たか + くなかった → 高たかくなかった（비싸지 않았다）
〜くて연결형 "~하고/~해서"高たか + くて → 高たかくて（비싸고/비싸서）
〜く부사형 "~하게" (뒤에 동사 수식)高たか + く → 高たかくなる（비싸게 되다）
〜ければ가정 "~하면"高たか + ければ → 高たかければ（비싸면）
〜そう양태 "~해 보인다"高たか + そう → 高たかそう（비싸 보인다）
예외. いい(좋다)는 어간 자체가 良(よ)로 바뀐 뒤 어미가 붙습니다 — 良くない, 良かった, 良さそう. 「いい」 그대로는 기본형·정중형에서만 씁니다.

な形容詞の語尾

な형용사 어미

な형용사는 어간 그대로(변형 없이) 명사처럼 어미가 붙습니다. だ・です・な・に 등 뒤에 오는 어미가 문법적 역할을 결정합니다.

01 — 어간 그대로 사용

어간 만들기 (사실상 변형 없음)

어간이란

사전에 실리는 형태 자체가 어간입니다. 명사와 똑같은 방식으로 어미가 붙습니다.
예) 静しずか(조용함) → 어간은 静しずか 그대로

어미의미결합 예시 (静か)
〜だ반말체 "~하다"静しずか + だ → 静しずかだ（조용하다）
〜です정중형 "~합니다"静しずか + です → 静しずかです（조용합니다）
〜じゃない / ではない부정 "~하지 않다"静しずか + じゃない → 静しずかじゃない（조용하지 않다）
〜だった과거 "~했다"静しずか + だった → 静しずかだった（조용했다）
〜でした과거 정중 "~했습니다"静しずか + でした → 静しずかでした（조용했습니다）
〜じゃなかった / ではなかった과거 부정 "~하지 않았다"静しずか + じゃなかった → 静しずかじゃなかった（조용하지 않았다）
〜で연결형 "~하고/~해서"静しずか + で → 静しずかで（조용하고/조용해서）
〜に부사형 "~하게" (뒤에 동사 수식)静しずか + に → 静しずかになる（조용해지다）
〜な명사 수식형 "~한"静しずか + な → 静しずかな部屋へや（조용한 방）
〜なら(ば)가정 "~라면"静しずか + なら → 静しずかなら（조용하면）
〜そう양태 "~해 보인다"静しずか + そう → 静しずかそう（조용해 보인다）
